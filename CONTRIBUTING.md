# Contributing Guidelines

## Branch Naming
- Use descriptive, lowercase branch names.
- Separate words with hyphens.
- Include a task identifier when applicable.

## Commit Messages
- Use clear, concise commit messages.
- Use prefixes such as `docs:`, `feat:`, `fix:`, `test:`, and `chore:`.

## Pull Request Rules
- Open a pull request into `main`.
- Explain the changes in the pull request description.
- Ensure required checks pass.
- Request review from the code owners.
- Merge after required approvals.
